# Flood Dataset

This dataset contains sample environmental and rainfall data for the SIH26085 Urban Flood Nowcasting System.

## Units

- rainfall: mm/hr
- water_level: m
- soil_saturation: 0–1
- elevation: m
- slope: degrees
- imperviousness: 0–1
- drainage_capacity: L/s
- drainage_capacity_used: L/s

The current dataset uses sample/mock values for prototype development.
Real datasets can replace these values during later development.
